# Atlas Usage

Design package guide for SenWeaverCoding agents and reviewers.

## Read Order

1. Read this file for the package contract.
2. Read `DESIGN.md` for visual intent, constraints, and anti-patterns.
3. Paste the `:root` block from `tokens.css` into the first artifact `<style>`.
4. Use `components.manifest.json` for the component inventory and token bindings.

## Design Highlights

- Warm sand surfaces with a sunset-coral accent (`#e0563b`); ocean teal secondary inline.
- Fraunces/Playfair serif headlines (tracked tight) + Inter body and prices.
- Photo-forward generous radii (10/16/24px); floating booking and search panels.
- Circular icon buttons for save/share; warm soft elevation over imagery.

## Do

- Let photography lead; frame it with warm sand and soft radii.
- Reserve coral for booking, price, and save moments; keep booking flows clear.
- Use a white separator ring on icon buttons that float over images.

## Avoid

- Avoid cold pure-white utility surfaces and coral overuse.
- Avoid busy chrome that competes with destination imagery.
- Avoid raw hex outside the copied `:root` token block.
