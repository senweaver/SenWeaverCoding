# Pulse Usage

Design package guide for SenWeaverCoding agents and reviewers.

## Read Order

1. Read this file for the package contract.
2. Read `DESIGN.md` for visual intent, constraints, and anti-patterns.
3. Paste the `:root` block from `tokens.css` into the first artifact `<style>`.
4. Use `components.manifest.json` for the component inventory and token bindings.

## Design Highlights

- Charcoal stack with an electric volt accent (`#c8ff00`) — dark text on volt fills.
- Archivo/Oswald condensed display (uppercase) + JetBrains Mono live metrics.
- Big-number metric tiles and volt goal rings; very tight display leading.
- Sharp radii, kinetic motion, double volt focus ring on dark.

## Do

- Make the key metric the largest element; reserve volt for effort, records, and "go".
- Use dark `--accent-on` text on volt fills, never white.
- Use mono for live metrics (pace, HR, splits).

## Avoid

- Avoid volt as a background wash and low-contrast gray text.
- Avoid pastel "wellness" softness that drains the energy.
- Avoid raw hex outside the copied `:root` token block.
