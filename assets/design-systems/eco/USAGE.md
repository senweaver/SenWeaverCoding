# Terra Usage

Design package guide for SenWeaverCoding agents and reviewers.

## Read Order

1. Read this file for the package contract.
2. Read `DESIGN.md` for visual intent, constraints, and anti-patterns.
3. Paste the `:root` block from `tokens.css` into the first artifact `<style>`.
4. Use `components.manifest.json` for the component inventory and token bindings.

## Design Highlights

- Recycled-paper surfaces with a grounded forest-green accent (`#2f6b3f`).
- Fraunces/Lora serif display + Inter body, 17px at 1.6 leading for long reads.
- Honest impact stats with serif numerals; earthy non-neon chart palette.
- Soft organic radii and unhurried motion.

## Do

- Keep surfaces warm, the accent grounded, and impact data presented honestly.
- Use the serif voice for editorial warmth and authority.
- Derive chart colors from the earthy palette (greens, clay, sand, ochre).

## Avoid

- Avoid fluorescent "eco-green" neon and glossy gradients.
- Avoid greenwashed superlatives that undermine trust.
- Avoid raw hex outside the copied `:root` token block.
